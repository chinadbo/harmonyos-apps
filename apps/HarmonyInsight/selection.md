# 今日选题：HarmonyInsight — 数据可视化图表工具

## App 名称
HarmonyInsight

## 品类标签
数据可视化 / 图表工具 / 效率工具

## 定位
一款轻量级数据可视化工具，支持导入 CSV/手动输入数据，生成交互式图表（柱状图、折线图、饼图、散点图、雷达图），支持图表分享与导出。

## 核心功能
1. **数据导入**：手动输入表格、CSV 文件导入、示例数据
2. **图表类型**：柱状图、折线图、饼图、环形图、散点图、雷达图、面积图
3. **图表配置**：颜色主题切换、标签显示、图例开关、数据点标记
4. **交互操作**：图表缩放、数据点点击高亮、长按查看详情
5. **导出分享**：截图保存到相册、分享为图片、导出数据为 CSV
6. **历史记录**：最近查看的图表列表，支持重新编辑

## 技术亮点
- Canvas 自定义图表渲染（纯前端绘制，不依赖第三方图表库）
- 文件管理（fs API 读取 CSV）
- 照片权限（保存图表截图到相册）
- 数据持久化（RDB 存储图表历史）
- 响应式布局适配不同屏幕尺寸
- 动画过渡效果（图表加载/切换动画）
- 暗色/浅色主题切换

## 复杂度评估
- 难度：中大型
- 预估文件数：15-20 个 ETS 文件
- 核心难点：Canvas 图表渲染逻辑、CSV 解析、RDB 数据模型
- 预计编码时间：60-75 分钟
